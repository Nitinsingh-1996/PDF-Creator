HTML to PDF starter file

Build your PDF by editing this HTML file.

This is now a clean dummy template. Replace this content with your real report, brochure, or guide, then click Generate PDF in the app.

How it works
  1. Edit the HTML inside retirement_readiness_guideNew.html.
  2. Create each PDF sheet with a <div class="page">.
  3. Put your visible content inside <div class="page-body">.
  4. Use the preview on the left to check layout before generating the PDF.
Recommended structure
  • Use one .page per PDF page.
  • Add .running-header and .running-footer for repeating chrome.
  • Keep spacing inside .page-body, not on the page wrapper.
  • Use inline CSS in this file for reliable PDF rendering.

Example

Copy this structure when you create a real page.

The PDF renderer already understands this layout. If you need more pages, duplicate the whole .page block and replace the content. 

<div class="page">
  <div class="running-header">
    <span>My Document</span>
    <span>Page Header</span>
  </div>

  <div class="page-body">
    <h2>Your section title</h2>
    <p>Add paragraphs, images, tables, or callout boxes here.</p>
  </div>

  <div class="running-footer">
    <span>Company or note</span>
    <span>2026</span>
  </div>
</div>

Good things to add

  • Headings, paragraphs, and simple lists
  • Images with fixed width values
  • Tables for structured information
  • Small callout boxes for summaries

Things to be careful with

  • Very large images that overflow the page
  • Absolute positioning for normal content blocks
  • External fonts that may not load in PDF generation
  • Huge unbroken text blocks without spacing
Tip: if you want a quick starting point, keep this file's CSS and only swap the content inside each .page-body. That gives you a stable PDF layout with much less cleanup.
